**En estudio:**
- OWASP Top 10: inyección, autenticación rota, control de acceso, configuración insegura.
- Autenticación y autorización en ASP.NET Core (Identity, JWT, roles y políticas).
- Manejo seguro de contraseñas, secretos y datos sensibles.
- Fundamentos de redes y Linux.

**Plan para aplicarlo en mis proyectos:**
- [ ] Autenticación JWT y autorización por roles en la API de la Cooperativa
- [ ] Validación de entradas y consultas parametrizadas revisadas
- [ ] Secretos fuera del repositorio (User Secrets / variables de entorno)
- [ ] Análisis de dependencias y código en GitHub (Dependabot / CodeQL)
- [ ] Documentar un modelo de amenazas básico por proyecto
